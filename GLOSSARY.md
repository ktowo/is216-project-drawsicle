# Drawsicle

Online art exchanges (Secret Santas and art trades) for hobby communities: organisers run events, artists offer their characters and make gifts for each other.

## Language

**Character**:
An original character in someone's private library, offered to artists in exchanges.
_Avoid_: OC (in the UI), avatar

**Colours**:
The up-to-six swatches that define how a character looks; the character's screen pet takes its colours from them too.
_Avoid_: Palette (reserved for a pet's preset colour scheme), swatch set

**Share card**:
An image of one event (its stage, dates, real counts and a QR code to its page) that anyone allowed to share the event can download or post.
_Avoid_: Hype card, poster, banner (the event's own header image)
